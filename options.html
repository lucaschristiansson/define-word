Merriam-Webster API key

Add a free key to get definitions from Merriam-Webster instead of the Free Dictionary. Register at dictionaryapi.com and pick Collegiate Dictionary as one of the APIs, then paste that key below.

Security

  • Your key is stored only on this device, in the add-on's local storage. It isn't synced.
  • It's only ever sent to dictionaryapi.com over HTTPS. Web pages and the popup never see it.
  • After saving, only the last 4 characters are ever shown.

Shortcuts

Select a word and press Alt+Shift+D, or right-click → Define. You can change the shortcut at about:addons → ⚙️ → Manage Extension Shortcuts.
